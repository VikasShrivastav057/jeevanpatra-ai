# AI profile photo movement

Implemented 31 October 2026.

AI finishing now supports `profilePhoto.offsetX` and `profilePhoto.offsetY` on every template. These translate the profile-photo frame independently of its normal layout or existing manual placement. Offsets use percentage points of the A4 content area, with right/down positive, left/up negative, and a bounded cumulative range of -20 to 20. The vertical conversion preserves the A4 aspect ratio. The existing manual controls remain available for larger adjustments.

The editor sends only the numeric current offset and rendered photo bounds. It does not send the photo URL, file, pixels or crop to Groq. A precise request such as the customer's 1% right/down prompt is resolved directly and reviewed before applying; no provider call is required. The validator rejects omitted axes, wrong directions/amounts, off-page movement, unrelated shape/style changes, missing photos and position-preservation conflicts.

The adjustment is persisted with the existing `photoAdjustment`. Offset-only records preserve default image styling exactly; existing crop/zoom/manual placement remain intact. The renderer translates the frame without reflowing the name or details. Saving succeeds before the visible position changes. Reload, completion signatures and the isolated A4 PDF retain the offset. Entering manual move mode folds the visual offset into the manual position to avoid a jump or double application; reset controls clear the appropriate adjustments.
